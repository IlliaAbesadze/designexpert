# Motion spec

Уровень — «мягкий»: короткие появления, прочерчивание линий, плавные раскрытия.
Без библиотек: CSS transitions/keyframes, `@starting-style`, IntersectionObserver, Web Animations API.

## Токены (`src/styles/tokens/_motion.scss` → CSS-переменные)

| Токен              | Значение                         | Где                                |
| ------------------ | -------------------------------- | ---------------------------------- |
| `--duration-fast`  | 200ms                            | цвета при наведении                |
| `--duration-base`  | 450ms                            | аккордеон, меню, иконка плюс/минус |
| `--duration-slow`  | 900ms                            | появления                          |
| `--duration-line`  | 1200ms                           | линии, масштаб картинки в reveal   |
| `--ease-out`       | `cubic-bezier(0.16, 1, 0.3, 1)`  | появления, раскрытия               |
| `--ease-in-out`    | `cubic-bezier(0.65, 0, 0.35, 1)` | линии                              |
| `--motion-shift`   | 24px                             | сдвиг fade-up                      |
| `--motion-stagger` | 90ms                             | шаг каскада                        |

## Пресеты (атрибуты в разметке)

| Хук                   | Что происходит                                                     |
| --------------------- | ------------------------------------------------------------------ |
| `data-anim="fade-up"` | прозрачность 0→1 и сдвиг 24px вверх при входе в экран              |
| `data-anim="fade"`    | только прозрачность                                                |
| `data-anim="reveal"`  | маска `clip-path` сверху вниз, картинка внутри 1.08→1              |
| `data-line`           | разделитель (`::after`) прочерчивается слева направо `scaleX(0→1)` |
| `data-intro="1…6"`    | первый экран: CSS-анимация при загрузке с каскадом, без JS         |

Соседние элементы, вошедшие в экран вместе, получают задержку `n × 90ms` (максимум 6 шагов).
Каждый элемент анимируется один раз. Заголовок `h1` (LCP) не анимируется.

## Переключения

- **Аккордеоны** — WAAPI по высоте + прозрачность 450ms; соседний пункт сворачивается
  одновременно; плюс превращается в минус поворотом и схлопыванием черты.
- **Меню** — popover: fade + сдвиг через `@starting-style`, пункты каскадом по 40ms.
- **Наведение** — цвета ссылок, строк Feedback и разделителей за 200ms; верхняя линия
  бургера дотягивается до полной ширины.

## Деградация

| Режим                           | Поведение                                                |
| ------------------------------- | -------------------------------------------------------- |
| full                            | всё по спеке                                             |
| `prefers-reduced-motion`        | `motion-ready` не ставится, контент виден, переходы ~1ms |
| нет JS / ошибка скрипта         | стартовые состояния не применяются, аккордеоны нативные  |
| нет Popover / `@starting-style` | меню без анимации появления                              |

Анимируются только `transform`, `opacity`, `clip-path` (и высота контента аккордеона).
CLS от анимаций — 0 (проверяется в `tests/e2e/motion.spec.js`).
